# 吴欣恺的机器人学习项目展示

[English](README.md)

我是南方科技大学自动化专业本科生，关注机器人学习、VLA、世界模型及机器人操作中的强化学习。本仓库展示此前学习、复现与工程探索中的四项工作，便于快速了解我的参与内容、实验过程和结果。

## 项目入口

| 项目 | 主要工作 | 目前有证据支持的结果 |
| --- | --- | --- |
| [PI0.5／FluxVLA 复现](projects/01-vla-reproduction.md) | 数据核查、LoRA 配置、训练与离线评估 | 30,000 步训练；10 个验证 episode 的动作 MAE 为 0.017701，未做真机闭环成功率评估 |
| [手套到灵巧手的重定向](projects/02-glove-retargeting.md) | ROS 2／MuJoCo 接口及独立自碰撞过滤模块 | 已整理实现和验证协议；目标平台运行结果仍待量化验证 |
| [接触约束动作重定向](projects/03-contact-retargeting.md) | 坐标与关节适配、优化实验、漂移／接触／穿透诊断 | 已建立运动学基线并比较参数；低学习率试验降低采样穿透，但接触质量仍未达标 |
| [灵巧手分阶段 RL](projects/04-staged-rl.md) | PPO 接近、冻结策略交接、参考辅助抓握、连续推理 | 固定场景接近误差约 1.473 mm；抓握仍有参考与固定抬升，尚未证明学习增益或广泛泛化 |

上述工作是相关的学习与实验积累，尚未打通为完整系统。VLA 没有部署到本灵巧手仿真；当前 RL 策略没有实时触觉输入；运动学回放也不等于物理操作成功。

## 我的工作与项目来源

主要参与复现环境与配置、数据及接口核查、模块集成、实验运行和结果分析。实现过程中有研究指导和 AI 工具协作；上游模型、供应商逆运动学及既有方法均在项目页和 [来源说明](NOTICE.md) 中区分。

结果摘要见 [results](results/README.md)，公开内容说明见 [release notes](docs/release-notes.md)。项目介绍以英文为主，方便科研交流。
