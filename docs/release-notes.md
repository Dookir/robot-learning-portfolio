# Portfolio release notes

## Purpose

This is a documentation portfolio for research discussion, reviewed on 16 November 2026. It presents selected work by Xinkai Wu and the interpretation of recorded experiments. It is not a release of the lab's development environment or a complete executable reproduction package.

## Included material

- Newly written English project pages and a Chinese overview.
- Original Mermaid diagrams explaining the method and controller boundaries.
- Selected scalar results, configured parameters and evidence-status notes in JSON.
- A dependency-free checker for this portfolio's file inventory, links and basic content consistency.

No private development repository is required to read the pages. The JSON summaries support inspection of the numbers displayed here; without the original data and runtime they do not allow independent reproduction of the experiments.

## Interpretation

The experiments took place in September and October 2026. Preparing this release did not rerun model training, ROS deployment or physical robot tests. The glove project's recorded validation file is a template, so this portfolio reports its implementation and pending measurements separately.

Reproduction engineering, interface work and experiment analysis are distinct from inventing the upstream models or proving a new research hypothesis. Contributions were developed with research guidance and AI-assisted implementation. Future work appears explicitly as future work.

## Distribution boundary

This repository contains no original robot recordings, source dataset samples, hand/object meshes, MANO assets, vendor IK implementation, checkpoints, credentials, machine-specific configuration, private development history or source logs. Rendered scenes and recorded videos are omitted because their model/data redistribution status has not been established for this release.

The source development repositories retain their existing visibility. No claim is made that an existing private repository is safe to publish as a whole.
